How Quoth turns speech into state

The LLM only proposes. Deterministic code decides, and every step is written to an append-only log.
1 · Hear

Deepgram Flux

Streaming speech-to-text. Emits a turn when the speaker finishes, with every word's timestamp and confidence.

2 · Interpret

Claude

Proposes operations (add, update, remove, confirm, deny). Each one cites the exact word span it came from, or marks the turn unclear.

proposes only
3 · Verify

Verifier

Does the quote match those words? Is the number spoken? Is the value on the menu? Is there exactly one target?

deterministic
4 · Gate

Confidence gate

Field confidence = lowest word confidence in the cited span. Critical fields need 0.80, normal fields 0.65.

deterministic
5 · Ask

Clarify

Templated questions about the riskiest open item, within a budget of 3. The rest is read back at the end.

deterministic
